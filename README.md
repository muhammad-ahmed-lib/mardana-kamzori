# Mardana Kamzori

Men's Wellness & Vitality Support website by Hakim Faizan Lohapar.

**Live site (GitHub Pages):** https://muhammad-ahmed-lib.github.io/mardana-kamzori/

## Enable GitHub Pages (required once)

1. Go to the repository **Settings** → **Pages**
2. Under **Source**, select **Deploy from a branch**
3. Choose branch **main** and folder **/ (root)**
4. Click **Save**

After about 1 minute the live site will be available at the link above.
